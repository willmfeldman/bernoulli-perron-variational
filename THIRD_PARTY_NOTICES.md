# Third-party code

This project is released under the Apache License 2.0 (`LICENSE`). It contains no code copied or
adapted from other projects.

It uses these Lake dependencies as ordinary libraries: Mathlib; viscosity-solution-theory
(https://github.com/willmfeldman/viscosity-solution-theory, v0.2.0), which pulls in
aleksandrov-differentiability; parabolic-basic-theory
(https://github.com/willmfeldman/parabolic-basic-theory, v0.1.0); bernoulli-parabolic-comparison
(https://github.com/willmfeldman/bernoulli-parabolic-comparison, v0.1.0); gmt-foundations
(https://github.com/willmfeldman/gmt-foundations, v0.1.0); elliptic-bernoulli-foundations
(https://github.com/willmfeldman/elliptic-bernoulli-foundations, v0.1.0); and
bernoulli-rectifiability (https://github.com/willmfeldman/bernoulli-rectifiability, v0.2.0).
All are Apache-2.0.
